## Одна логика для сабмита и веб-чата

`ContextEngine.prepare` выбирает положения, короткие полные документы и связанные дополнительные соглашения. Обработка истории диалога, метаданные редакций и предупреждения о применимости входят в контекст генерации. Поиск использует локальные BM25/TF-IDF и маршрутизацию по документам. Доступные сервисы BGE/Qwen остаются возможностью развития, в этой версии они не участвуют в поиске.

`Model` обращается к OpenAI-совместимому прокси с моделью из окружения. `answer_one` использует общий промпт, проверяет ссылки и числа, запрашивает целевое исправление и сохраняет подтверждённую часть при сбое повторного запроса. Ответ о пробеле в базе допускается и при наличии близких по теме фрагментов. Проверка чисел учитывает русскую запись числительных и единицы измерения.

Пакетная точка входа `solution.py` создаёт `submission.csv`. Веб-адаптер `contender_service.py` вызывает те же `ContextEngine`, `Model` и `answer_one`, преобразует точные ссылки в структуру HTTP API и сохраняет доступ к исходным фрагментам и полным документам. Постоянные диалоги, идентификаторы запросов и API-маршруты сохранены. Старый `ML2Generator` доступен для сравнительных проверок и явно переданного генератора.

Веб-запрос имеет общий бюджет 300 секунд, настраиваемый через `PSB_REQUEST_TIMEOUT`. Один вызов модели по умолчанию ограничен 85 секундами. Бюджет пакетного запуска составляет 1160 секунд с резервом относительно лимита платформы 20 минут. `MAX_WORKERS` ограничивает параллельные обращения. Базу можно передать как `knowledge-base.zip`, `knowledge_base.zip` или `kb.zip`.

## Воспроизведение

```sh
python -m pip install -r requirements-api.txt
python -m unittest discover -s tests -v
python scripts/build_submission.py --output dist/submission.zip
python tests/verify_submission.py dist/submission.zip data/questions.csv data/knowledge-base.zip
```

Вторая команда проверяет HTTP-контракт, постоянные диалоги, общий конвейер и регрессии. Последняя команда запускает распакованный ZIP через локальную имитацию модели. Для реального запуска задайте `DATA_DIR`, `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL` и выполните `python solution.py`. Платформа предоставляет свои входные файлы и параметры прокси автоматически. Значения ключей в репозиторий и архив не включаются.
