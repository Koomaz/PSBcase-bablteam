# Записка backend-разработчику

В `Service.ask` добавлен вызов `retriever.evidence_packet(...)` **до** построения списка допустимых ID цитат. Поэтому новые положения короткого документа можно цитировать и открывать через прежний API; неизвестные ID по-прежнему запрещены. Формат HTTP-запроса и CSV не изменён.

В `ML2Generator` по умолчанию включена семантическая проверка той же моделью из окружения. Нормальный ответ требует 2 вызова, исправление с повторной проверкой — обычно 4; `MAX_LLM_CALLS=5` ограничивает число логических вызовов на вопрос (внутренние HTTP-повторы отдельно). После отрицательного вердикта или сбоя reviewer выдаётся безопасное сообщение о недостаточном подтверждении, а не отвергнутый черновик. Пустой evidence не вызывает модель. Для подтверждённого частичного ответа используется существующий `kind=partial`.

В `.env.example` и `compose.yaml`: `ANSWER_REVIEW=1`, `PSB_EVIDENCE_MODE=adaptive`, `MAX_LLM_CALLS=5`, `PSB_REQUEST_TIMEOUT=60`. Общий бюджет batch остался 19 минут. Эти настройки требуют замера задержек на прокси организаторов. `ANSWER_REVIEW=0` отключает смысловую защиту и нужен только для сравнения; `PSB_EVIDENCE_MODE=baseline` отключает расширение пакета.

Логгер `psb_backend` на уровне INFO пишет число вызовов, итоговый kind, длительность, число проверок/исправлений/отклонений и отброшенных фрагментов. Тексты вопросов и ключи в эти логи не добавлены. Подключите INFO-обработчик в конфигурации вашего запуска. Ошибки batch по-прежнему считаются в итоговом `failures`.

Сборка: `python scripts/build_submission.py --output dist/psb-submission.zip`. ZIP содержит только 16 корневых файлов, зависимость `httpx==0.28.1`; веб-зависимости и тесты не попадают в сабмит. Обновлён `tests/verify_submission.py`: имитация прокси теперь отвечает и на reviewer.

Проверены ML1, ML2, разрешение расширенных цитат и весь ZIP на 18 демо-строках. FastAPI/Docker здесь не проверены: FastAPI отсутствует, Docker daemon недоступен. Настоящий DeepSeek/judge недоступен; рост платформенного балла не заявляется. Полные результаты — `docs/ml-quality-20261112.md`.
