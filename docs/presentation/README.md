# Презентация решения

- [PDF для экспертной проверки](psb-bablteam.pdf)
- [Редактируемый исходник PowerPoint](psb-bablteam.pptx)

Основная часть содержит 12 слайдов: задачу юриста, интерфейс, пример проверки ошибочной предпосылки, поиск и подготовку контекста, даты и редакции, контроль ответа, результаты проверок, воспроизводимый запуск и план пилота. Первый слайд содержит кликабельную ссылку на репозиторий и порядок проверки.

## Как проверить продукт

1. Подготовить базу организаторов и конфигурацию прокси по корневому [README](../../README.md), запустить `docker compose up --build -d --wait`.
2. Открыть `http://localhost:8000`, задать вопрос о предоплате по договору с «Альфа-Трейдинг» и открыть ссылку на п. 4.2 договора ПТ-05/2023.
3. Проверить вопрос о договоре на 12 млн рублей в августе 2024 года, запрос с ошибочной суммой арендной платы и вопрос о размере пособия. Сопоставить ответы с источниками и [таблицей приёмки](../acceptance.md).

## Основания числовых утверждений

Результат последнего улучшенного ZIP — **20.139 балла**, по сообщению участника команды от 16.11.2026. Продолжительность прогона и текущую позицию команда отдельно не сообщала. Значение сохранено в сообщённой шкале платформы. История версии и исходного архива описана в [журнале сабмитов](../submissions.md).

Проверки CSV, повторных запросов и числовых ссылок используют имитацию генерации. Набор из 25 дополнительных запросов проверяет наличие 26 целевых положений в контексте. Эти проверки отражают разные свойства решения. Полнота юридического ответа и бизнес-эффект требуют отдельной оценки на реальной модели и пилота с юридическим подразделением.

Примеры аренды и порогов одобрения подготовлены по базе хакатона и помечены как контрольные. Скриншот показывает интерфейс из репозитория. Обложка — концептуальная иллюстрация документов, созданная встроенным imagegen. Промпт: «Редакционная композиция для юридического ассистента: светлый фон, вертикальные листы документов справа, полупрозрачная оранжевая закладка и тёмная стеклянная плоскость, выделяющая положение; свободная левая половина под заголовок; без текста и логотипов».
