# Отчёт проверки backend

Дата проверки: 10 ноября 2026 года. Проверка выполнялась на локальном macOS/arm64 с Docker Desktop. Это инженерная проверка воспроизводимости, поиска, HTTP-контракта и формата сабмита, а не подтверждение юридической правильности ответов.

## Результаты

| Проверка | Результат |
|---|---|
| Unit-тесты backend | 16/16 после добавления обработки сбоя поиска; до этой правки было 15/15 |
| Демонстрационный ZIP | 18/18 строк, 0 failures, 18 вызовов временной имитации модели, 0,517 с, пик RSS 108,0 MiB |
| Корпус | 21 документ, 822 уникальных чанка; обязательные поля заполнены, пустых текстов и повторяющихся ID нет |
| Docker-образ | Сборка из закреплённого Python 3.12.12 прошла до финальной правки обработки сбоя поиска |
| Compose | Readiness, чат, фрагмент источника, история, независимые запросы, отсутствие доказательств, 401, тайм-аут и отклонение path traversal прошли до финальной правки; после неё контейнер не пересобирался |

Команды проверки:

```sh
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python scripts/build_submission.py
.venv/bin/python tests/verify_submission.py dist/submission.zip data/questions.csv data/knowledge-base.zip
docker compose build backend
.venv/bin/python tests/verify_docker.py
```

`tests/verify_submission.py` запускает распакованный ZIP в отдельном рабочем каталоге и использует временный HTTP-прокси, который возвращает заранее заданные ответы. `tests/verify_docker.py` также поднимает временный прокси и отдельный Compose-проект, после чего удаляет контейнер и сеть. Значения ключа в тестах фиктивные. Эти проверки подтверждают формат CSV, интеграцию ZIP, обработку истории и ошибок, но не качество ответа реальной модели. После финальной правки обработки сбоя retrieval повторно прошли unit-тесты 16/16 и сборка ZIP; повторная Docker-сборка не выполнялась.

## Что не проверено

- Нет действующих `LLM_BASE_URL`, `LLM_API_KEY` и `LLM_MODEL`, поэтому реальный DeepSeek V4.1 Flash, доступность прокси, задержки и качество генерации не проверены. Файл `.env` отсутствует.
- ZIP не отправлялся на платформу. Формат, CSV и структура архива проверены локально, но приём платформой и её ограничения неизвестны.
- Фронтенда в репозитории нет. HTTP-интеграция проверена тестовым клиентом; реальное открытие фрагмента в интерфейсе не проверено.
- Юридическая корректность ответов, правильность выбора норм, актуальность редакций и применимость ссылок требуют экспертной проверки. Непустой ответ и наличие `chunk_id` этого не доказывают.
- Кросс-платформенность Docker-образа и digest базового образа вне macOS/arm64 не проверялась.

## Ограничения поведения

Без LLM-конфигурации API корректно возвращает `503 unavailable`, а Compose с `--wait` сообщает об unhealthy. Для реального запуска необходимо заполнить `.env` или переменные окружения; значения ключа нельзя добавлять в Git, ZIP или Docker-образ.

Сборка индекса и локальный поиск выполняются синхронно и не прерываются общим таймером Python. Бюджет 19 минут проверяется между вопросами; сетевые вызовы имеют отдельный тайм-аут.
