# Анализ базы знаний ПСБ

В предоставленной базе 21 документ в UTF-8 TXT. Исходные файлы читаются без OCR. PDF и DOCX в корне проекта содержат описание кейса и регламент сабмита. В корпусе нет сканов или отдельных файлов таблиц. У текстовых источников отсутствует нумерация страниц, поэтому ссылки используют структуру и смещения в исходном тексте. В артефактах сохранены 822 поисковых чанка из 21 документа.

## Разбор и цитирование

- Для договоров и регламентов заголовки разделов сохраняются как контекст. Преамбулы служат источником реквизитов и метаданных.
- Для законов парсер опирается на заголовок статьи, сохраняет явно обозначенные части, пункты и подпункты. Ненумерованные фрагменты цитируются по статье и диапазону символов. Редакционные пометки распознаются по шаблонам. Часть пометок сообщает даты изменений отдельных положений. Ссылки и дата выгрузки взяты из самих TXT.
- Для длинных фрагментов границы выбираются по предложению, строке или слову с перекрытием до 160 символов. Текст чанка можно извлечь из исходного файла по полуинтервалу `[char_start, char_end)`. Смещения считаются в символах Python после декодирования UTF-8 с учётом исходных переводов строк.
- Строка с директивой в ЮО-7 исключена из чанков и обоих видов индекса. Путь и смещения исключения сохранены в манифесте. Это эвристическая обработка обнаруженного шаблона. ML2 обрабатывает остальное содержимое источников как данные.
- Все файлы прочитаны. Исторические тексты законов в корпусе отсутствуют. Дата редакции регламента 2023 года используется как нижняя граница ранжирования при отсутствии отдельной даты вступления в силу. Оба значения разнесены в метаданных.

Парсер ориентирован на структуру этой поставки. Сложная вложенность списков, переходные положения и сроки с условиями продления требуют проверки по исходному тексту. Например, договор ПТ-05/2023 содержит условие автоматического продления, поэтому одна календарная дата не определяет актуальность договора. Форматы кроме TXT и Markdown регистрируются как неподдерживаемые.
